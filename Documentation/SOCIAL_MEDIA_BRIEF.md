## Design Guidelines

### Do's ✅

1. **Maintain terminal aesthetic** - monospace font, high contrast, minimal
2. **Keep rust (#C25E30) as primary accent** - brand consistency
3. **Use actual screenshots** - authenticity over perfection
4. **Center align all text overlays** - clean, professional
5. **Add semi-transparent backgrounds behind text** - legibility
6. **Preserve JetBrains Mono exclusively** - no font mixing
7. **Keep composition minimal** - let the UI speak for itself
8. **Use subtle effects** - vignettes, glows (5-10px radius max)

### Don'ts ❌

1. **Don't add gradients** - flat colors only
2. **Don't use rounded corners** on overlays - keep sharp edges
3. **Don't over-edit screenshots** - minor color tweaks only
4. **Don't mix fonts** - JetBrains Mono exclusively
5. **Don't add decorative elements** - no icons, shapes, patterns
6. **Don't use drop shadows** - glow effects only (for specific elements)
7. **Don't change the UI** - show it as-is
8. **Don't make text too small** - minimum 18pt for readability
